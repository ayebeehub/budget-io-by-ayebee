# Third-party notices for the offline preview

The self-contained `budget-io-preview.html` embeds the local UMD distribution of React 16.0.0 and ReactDOM 16.0.1 for demonstration in an execution environment where npm package downloads were unavailable. The main TypeScript/Vite application declares React 19 dependencies separately. The demo's embedded React is not intended for deployment.
